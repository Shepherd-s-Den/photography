# Shared [SDD](https://github.com/cosminci/agentic-workflows)

- From the repository root, run `bash scripts/workflows context`.
- Read the returned entrypoint and localGuidance before doing work.
- Follow the entrypoint's mandatory load matrix for the current phase; record loaded paths/revisions.
- Keep the returned revision in work state and reuse `--revision` for this task.
